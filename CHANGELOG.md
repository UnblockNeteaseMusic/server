# Changelog

## 0.29.0 (2026-11-25)

### TL; DR;
- Run yt-dlp in the Docker image with the Node.js runtime
- Support the xeapi encryption
- Standalone executables embed Node.js 26 and run on macOS
- Handle the Bilibili API errors
- Fix the Kuwo track API
- Scope the header overrides and correct the fallback
- Survive a refused response and an entry without a URL
- Show the local VIP badge
- Releases are built in a Nix dev shell, signed and published without tokens
- Renew the default certificate
- Replace the JOOX API
- Support newer Netease clients
